CONFIGURED DOWNLOAD: keep point6miner-settings.json beside the app. Your public details fill in automatically; press Start Mining after checking them.

POINTSIXPOOL MINER — QUICK START

WINDOWS PC
1. Open PointSixPool Miner.exe.
2. Paste your public ZEC receiving wallet address.
3. Give this machine a name, for example Home-PC.
4. Leave performance on Auto and press Start Mining.
Press Stop Mining to stop. Closing the app also stops mining.
No Python or .NET installation is needed for the Windows app.

LINUX DESKTOP
1. Extract the complete Linux download.
2. Open Start-Desktop and choose Run if your file manager asks.
3. In the browser window, enter your wallet and machine name.
4. Leave performance on Auto and press Start Mining.
If your file manager opens the launcher as text, open a terminal in
this folder and enter: ./Start-Desktop
Linux needs Python 3 and taskset (util-linux). The mining runtime is bundled.
Use your normal account, not root. Close/stop the miner when finished.

LINUX SERVER (NO DESKTOP)
1. Extract the complete Linux download and open its folder.
2. Enter: ./Start-Server
3. Paste your public ZEC wallet address and give this machine a name.
4. Press Enter to keep Auto performance.
5. Choose whether to enable automatic startup.
Saving setup starts mining. Ctrl+C stops a foreground miner.
For an automatic worker: ./Start-Server --stop
To disable automatic startup: ./Start-Server --disable-autostart
To change wallet or machine name: ./Start-Server --setup
Automatic startup uses your Linux user service. Startup before login
requires administrator-enabled user lingering; setup checks and reports it.

YOUR STATS AND EARNINGS
Click View my stats & earnings in the app. Wallet miners see their public
worker group; registered miners sign in to view their account. The Linux
server wizard prints your dashboard link. Work and actual earnings are
separate: accepted shares do not guarantee an immediately payable balance.

WHAT TO EXPECT
ZEC MICRO is selected automatically. No pool address needs typing.
Choose EU, USA or ASIA; the matching URL is selected automatically.
All three choices currently connect to the same server in Europe.
PPLNS and SOLO are separate pool modes; this app stays MICRO-only.
This version uses your CPU, not your graphics cards. It requires an
AVX2-capable 64-bit CPU and 1 GiB available memory for one CPU thread, plus 0.5 GiB per extra thread.
Accepted shares mean work was accepted, not money already earned.
Rewards need eligible work and mature pool blocks. Electricity may cost
more than earnings. Pool fee: 0.6%. MICRO minimum payout: 0.001 ZEC.

AUTO, TEMPERATURE AND POWER
Auto begins conservatively. Stop before changing the speed slider.
Supported Linux CPU sensors enable speed reduction at 75 C and stopping
at 85 C. Missing sensors show unavailable. On Windows, supported readings
can come from LibreHardwareMonitor while it is running; it is optional and
not installed by this app. Keep your computer's normal cooling enabled.
Official sensor provider: https://github.com/LibreHardwareMonitor/LibreHardwareMonitor
CPU-package power excludes the rest of your computer. Measured presets
need sufficient real accepted work and valid energy samples; otherwise Auto
keeps its conservative default. No benchmark starts mining automatically.

Only enter your PUBLIC receiving wallet address. Never enter a seed,
private key, wallet passphrase or payment password.
Help and current pool rules: https://pointsixpool.com/point6miner

SIMPLE SERVER INSTALL (upcoming release): choose Linux server on the miner page, copy the generated root installation command, then run /start-mining. Stop with /stop-mining. The installer never starts mining; the service runs as pointsix-miner, not root.

Diagnostics: use Copy diagnostics. Code guide: docs/TROUBLESHOOTING.md
A confirmed connection loss retries fresh work after 10 seconds only with all submitted shares accounted for. Solver faults or uncertain acknowledgements stop without replay.

Performance: Auto remains conservative, with a maximum of 4 CPU threads. Stop mining to select up to 12 threads manually; the miner checks available CPU threads and free RAM before starting. Twelve threads require at least 6.5 GiB available RAM. Start low and increase gradually. Thermal protection requires a detected supported sensor.
