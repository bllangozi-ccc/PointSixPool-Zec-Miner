# Simple setup

Configured Windows and Linux downloads are available at https://pointsixpool.com/point6miner.

## Windows desktop

On https://pointsixpool.com/point6miner choose a public wallet or your saved mining ID,
a machine name, EU/USA/ASIA and Windows. Extract the complete configured ZIP, open
**PointSixPool Miner.exe**, check the prefilled details and press **Start Mining**.
Opening the download never starts mining automatically. No Python or .NET install is needed.

## Linux server: two steps

1. In your root server session, paste the installation command generated by the miner page.
2. After installation completes, enter `/start-mining`.

Installation downloads and checks the exact package, handles supported missing prerequisites,
and creates a dedicated `pointsix-miner` user. The actual miner never runs as root.
Stop with `/stop-mining`. Startup after reboot is optional and printed by the installer.
Uncertain share acknowledgements stop the service; they do not trigger automatic replay.
The .NET runtime is bundled. Current x86_64/AVX2 Linux and 1 GiB available RAM for one CPU thread, plus 0.5 GiB per extra thread are required.

## Linux desktop

Select Linux desktop and extract the complete configured ZIP. Open **Start-Desktop**.
It verifies and unpacks the runtime, loads your settings and opens the local browser UI.
Press Start Mining. Python3 and taskset are required; .NET is bundled.

## Your data and rewards

Settings contain only a public wallet or mining ID, machine name, region, ZEC and MICRO.
No website password, login token, payment key or seed is downloaded. Registered saved
mining IDs are read only for their signed-in owner. Public wallet mining needs no account.
All region names currently use one server in Europe. MICRO shares eligible PPLNS work;
accepted shares are not guaranteed earnings. Pool fee 0.6%; MICRO minimum 0.001 ZEC.
**View my stats & earnings** opens your public worker group or signed-in account dashboard.

## Advanced users

The original editable Linux archive and GitHub source remain available. This build is CPU-only.
GPU engines and mobile mining are not provided. Source changes are your own custom build.
